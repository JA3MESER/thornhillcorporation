Common questions

How will I hear back?

We'll reply by email to the address you enter in the form, so please double-check it before submitting.

What is my reference number for?

After submitting you'll get a reference like TH-AB12CD. Quote it if you need to follow up so we can find your enquiry quickly.

Can I send more than one enquiry?

Yes — but if it's about the same issue, one detailed enquiry helps us respond faster.
